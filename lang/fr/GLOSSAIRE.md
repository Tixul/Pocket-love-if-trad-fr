# Glossaire — Pocket Love if (VF)

## Règles
- ADAPTER, pas traduire : chaque réplique doit se comprendre seule, dite par CE personnage.
- Japonismes gardés (décision Tixul 20/11, comme Nige-Ron-Pa) : -kun, -san, -chan, -senpai,
  -sensei, onee-chan, onii-chan… Le reste est traduit.
- Noms dans l'ordre français : Prénom Nom. Joueur : `{F01} {F00}` (F01 = prénom, F00 = nom).
- `...` est compressé automatiquement en `{E03}` (mot du dictionnaire n°3 = « ... »).
- Boîte : 4 lignes de 144 px (4e : 136 px), 128 codes par message ; le build mesure tout.
